# Dependency maintenance

Inventory packages, backends, models, tools, actions and skills with declared
version, source bytes and updater owner. Cadence can become due without a source
commit. A bounded primary version response records source URL, response hash,
retrieval time and publication time. Version existence is not a latest-version,
security or compatibility claim. Security requires attributable advisory evidence;
an ordinary upgrade and an intentionally retained compatible pin remain distinct.
Cached evidence must be current for its selected period. Another updater owner
holds the overlapping operation.

Prepare candidates in isolation. Declaration edits, package-source retrieval,
runtime installation and service startup are independent permissions. Major,
backend, schema and storage changes take the protected review route. Candidate
checks never replace a live environment or claim a backend/model was installed.
A failed candidate leaves the existing environment intact. Current source and
runtime observations, when required, must use the separately selected owner.
