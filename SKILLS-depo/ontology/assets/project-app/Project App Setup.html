Prepare this Project app

The app could not start with the current local package or runtime. This page works without Python, npm, an internet connection, or a running depot.

  1. Ask your project maintainer to install the reviewed Project app assets through the project's selected adoption process. Keep your project content and existing setup receipt.
  2. Prepare Python 3.12 separately. The launcher checks this project's .venv/bin/python, then the standard Homebrew or system locations. It installs nothing.
  3. Check that project.json has this project's identity and project-app.json contains valid local content. Optional ontology or memory can remain unavailable.
  4. If package files changed while the app was running, stop that app from its existing tab, then double-click Launch Project.command again. Rebuilds and package updates belong to your maintainer.

Launch selects the folder containing the launcher and waits for authenticated readiness before opening Home. It can reopen only a compatible owned instance. A stale descriptor or occupied port never authorizes stopping another process.

Closing a tab leaves the app running. Close reading session revokes the shared browser session, including tabs using it. Stop app closes this reader service and all its reading sessions. Tasks, agents, watchers, and independent backends keep running.

If setup remains unavailable, share the bounded error code shown in the launch window with your maintainer. Do not share the private files under .sys4ai/project-app/; they contain temporary session credentials.
