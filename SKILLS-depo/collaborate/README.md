# Collaboration capability

The complete package is distributed in the neutral Sys4AI Template. Current
initializer create and prepare operations enable it by default after checked
local adoption, including selected projects with earlier completed setup receipts.
Custom or incompatible packages and guidance are preserved and block readiness.

Run the installed helper's read-only static check:

```sh
python .agents/skills/collaborate/scripts/collaborate.py --project-root /absolute/project health
```

Health compares the complete installed package against the completed setup-module
inventory or explicit root adoption receipt, exact reviewed owner pins and default
Task instructions. A reviewed inventory map may be supplied with --inventory-file.
This check executes no selected-project owner code and creates no Task or service.
A missing review record is unavailable, even when files are present.

The current owner profile supports orchestration versions 1 and 2. The exact depot
legacy profile supports version 1 only; it preserves the installed root Task owner
and offers no version 2 broker or current-input role acknowledgement proof.

Enabled installation supplies the default collaboration habit. Each execution
still needs its manager's registered scoped policy, current native assignments,
input bindings and grants. Reading, delivery, acknowledgement, material evidence
and canonical Task decisions remain separate. See [the skill](SKILL.md),
[commands](references/commands.md) and [Task integration](references/task-integration.md).
