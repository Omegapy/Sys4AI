assigned positions from proposed clocks, explained why index alone cannot define
speed, supplied a conditional length/time derivation, identified the missing
physical evidence for c, and preserved current review and owner dispositions.

This pair establishes useful workflow behavior, without establishing a quality,
speed, token-efficiency, or universal improvement.

The [frozen protocol](protocol.json) and [exact results](results.json) identify
the same packet, analysis-only extra-complex team, inherited effective settings,
initial candidate/review/synthesis allowance, and separate actual native context

parked, and resumed unchanged only after the adoption checkpoint. Both cases
retained two independent full-problem solvers, separately assigned first reviewers,
a distinct senior, and a separate manager. There was no implementation child.

The baseline window includes queues, read preflights, handoffs, two mandatory
schema-envelope corrections, and first acceptance. Earlier preparation/parking
is excluded. The enabled original window already includes required direct-peer
transport and restored-continuation validation. Later A2 and current re-review
extend its final validation window. There is no clean subtraction or causal
attribution of these unequal durations to collaboration.

Baseline communication measurements cover 48 manager native operations within
its original delivery window, 11 stored opaque handoff status receipts totaling
5870 UTF-8 bytes, and zero billboard posts/receipts. Those bytes are a narrow
receipt subset. Enabled measurements cover a different core-operation subset
through seniorV2: five spawns, five followups, one interrupt, 22 roster calls,
and 14 child messages. Its complete validation record contains nine posts
(16541 bytes) and 24 receipts (20498 bytes). Parent/wait/participant coverage
differs, so these counts are descriptive costs, not comparable total-system
prompt or efficiency measurements. Message count is not success.

Baseline recovery exercised an unchanged same-manager reconnect after clean
parking and mandatory candidate/synthesis envelope corrections. Enabled recovery
exercised a four-slot notice failure, preserved pending_init uncertainty, a
supported restored same-ID continuation, unchanged resume, and exact material
packet/input/followup gates. Existing bytes and versions survived; no extra
benchmark campaign was run.

Historical notified/uncertain labels are preserved. Actual mailbox observation,
exact acknowledgement, comprehension self-report, independently inspected output
incorporation, and pending delivery are separate evidence. Current receipt schema2
is a forward deterministic route; no historical receipt was rewritten.

Actual generic native behavior used the original V1 installation; enabled native
