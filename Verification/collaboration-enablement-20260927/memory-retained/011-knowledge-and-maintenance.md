# Existing knowledge and maintenance owners

A selected thread can support a concise pending proposal with source message IDs,
exact immutable source/target versions, independent evidence, suggested change,
validation and limitations. A useful answered conversation is not automatically
a verified lesson. The current owner evaluates evidence and privacy separately.
The adapter writes only the proposer's granted collaboration/proposals directory.
It invokes no memory, ontology, Curator, Task or native operation.

For memory, the current Director/confirmed manager inspects the adopted memory
skill and its existing task-integration and automatic-capture contracts. Only its
current bounded publication grant can publish a verified lesson through the normal
memory owner. Current-run discussions, proposals, drafts and reviews remain outside
initial solvers' frozen packet; new records never broaden an existing frozen set.
Do not change memory format, backend or automatic-capture preference.

For ontology, use the existing proposal-save/proposal-show/proposal-validate and
proposal-decide owner routes, followed by separately authorized proposal-publish.
Actual exact source/target, backend, helper and current grant checks remain required.
A discussion answer, accepted review or memory publication grant establishes no
scientific claim or ontology publication authority. Keep proposed assumptions
explicit and preserve their original source status.

For Curator, inspect the existing Application's public handoff/awareness routes and
current canonical delivery owner. A recurring concern is only a linked proposal,
not a new maintenance queue. The responsible Director/authorized Curator may select
an exact current offered correction through its normal owner workflow. Do not create
a duplicate Task, competing writer, unattended AI session or second queue.

Unavailable owner leaves the proposal status pending_owner. Posting, acknowledgement
or acceptance of a discussion answer performs no publication or maintenance. Retain
source thread, versions, evidence and limits while pending; preserve configurations,
canonical records and existing publication formats.
