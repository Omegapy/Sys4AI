# Non-active record examples

The five `MEM-*.md` files demonstrate decision, finding, experiment, lesson and
historical handoff shapes for the fictional `example-project`. They are drafts
with explicit null non-Task origins and no publication attribution. The
illustrative [evidence](evidence.md) is source material for the examples.

These files remain in the adopted reference collection. They are never active
memory, learned root knowledge, Template canonical records, or evidence that
implementation, verification or approval happened. Replace example content
and inspect real project evidence before proposing a note for publication.
