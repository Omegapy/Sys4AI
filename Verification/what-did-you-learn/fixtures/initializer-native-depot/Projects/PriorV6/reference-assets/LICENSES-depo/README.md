# Reusable Sys4AI licensing

This collection supplies the three-file licensing template requested for
Sys4AI projects. `LICENSE` defines the scope and attribution,
`LICENSE-CODE` contains Apache 2.0, and `LICENSE-DOCS` contains CC BY 4.0.

The default copyright holder is Alexander Samuel Ricciardi. The source's 2025
attribution and aliases are retained. Review project-specific copyright notices
when adding a new owner or newly authored material; preserve inherited notices.
Code examples use the code license even when embedded in documentation.
Separately licensed components and third-party material keep their own notices.

## Adoption and ownership

Edit reusable license content here. The depot's explicit mappings publish the
three files at the registered Template's root. This guide is published under
`reference-assets/LICENSES-depo/`; that reference copy describes the source
collection and does not override any project's active license notices.

Both project initialization routes read the three active files from the
Template. New projects and existing projects without license markers receive
the complete set. Preparation preserves existing licensing as a whole, including
partial sets and alternate names such as `LICENSE.md`, `licence.txt`, `COPYING`,
`COPYRIGHT`, `UNLICENSE`, or `LICENSES/`. Detection uses those root names
case-insensitively, including dot, underscore, or hyphen suffixes. Licensing
declared only inside unrelated prose or package metadata requires project review.

The initializer records original marker hashes separately from Template
source/adoption hashes. It skips missing companions when preserving an existing
system. Equivalent setup reruns verify the original edition; they do not add
licenses from a later Template or combine license systems. Changing an existing
project's licensing requires explicit project-specific adoption. Registration
does not authorize relicensing, bulk propagation, Git publication, or deployment.
