## Negative controls

Use distinct two-project sentinels; stale or absent source/config/index states; unsupported YAML and schema fields; credential, transcript and embedded-instruction fixtures; symlink, hardlink, alias and child-project paths; wrong publisher/generation/scope; human edits and concurrent writes; journal faults and idempotent retry; stale normalized TeX/PDF/HTML products; frozen note/source/packet versions; sibling copies; unsupported Task fields and legacy bytes; new/existing/old-edition initializer fixtures; Template add/change/remove/conflict/recovery; and actual local backend outage/write attempts. Native evidence must contain actual role reads, identities, launch/status/input receipts and complete required teams.

Known query relevance comes from the fixture source content. Measurements report observed conditions without invented speed, memory or quality thresholds.
