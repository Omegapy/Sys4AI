\section{Triangular totals}
For a positive integer $n$, the candidate total is
\begin{equation}
S_n = \sum_{k=1}^{n} k = \frac{n(n+1)}{2}.
\label{eq:triangular-total}
\end{equation}
The supplied arithmetic check evaluates $n=1$, $n=10$, and $n=100$.
These finite evaluations are examples, not a proof for every integer.
