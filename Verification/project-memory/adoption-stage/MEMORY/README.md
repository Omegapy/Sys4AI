# Project memory

This project owns its durable notes here. The starter contains no learned
records. Read the adopted [memory policy](../reference-assets/MEMORY-depo/policy.md)
and use the installed [memory skill](../.agents/skills/memory/SKILL.md).

Records are Markdown with validated JSON-compatible YAML frontmatter. Active
notes require scoped Director or confirmed Task-manager publication. Children
return drafts through assigned result artifacts. Current governing sources
and canonical Task/role state retain authority over remembered conclusions.

`memory.yaml` at the project root owns identity, source selection and runtime
paths. Direct reads and lexical lookup work without a backend. Examples in
the reference collection remain non-active examples and are never copied here.
