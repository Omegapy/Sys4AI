## Accepted behavior

Installation should enable Curator for live project-session use. The reusable Template stays neutral and each new destination is specialized. Maintenance catches up on return, uses finite work and model budgets, retains pending work when unavailable, and keeps routine success quiet. Unattended background AI stays off.

## Applicability and limits

This is an accepted design decision. Configuration, successful startup observation, completed owner operations and current retrieval are separate evidence levels. Existing opt-outs and old setup receipts are preserved.

## Improvement disposition

Use this decision as contextual recall when implementing or assessing Curator activation. Current instructions and direct checks govern each actual installation. Root adoption remains a separately verified project-local operation.
