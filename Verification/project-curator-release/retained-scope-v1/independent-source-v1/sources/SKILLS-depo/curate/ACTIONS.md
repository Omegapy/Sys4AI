# Curator actions

This candidate supports independent inspection and package functions. Connected
review, mutation, pause/resume and scheduled dispatch remain unavailable because
the current shared Broker lacks the control interface required by Application.
The conditional routes below are not evidence of operating readiness.

| Action | Effect and existing owner |
| --- | --- |
| status / validate | Inspect the bounded selected policy; never repair or analyze with a model. |
| review | Standalone scoped metadata, or authenticated bounded source-ownership analysis; no canonical writes. |
| update | Exact integration, memory/ontology publication or selected derived maintenance through the Broker. |
| correct | Exact reviewed integration or canonical owner lifecycle correction; independent authority remains required. |
| retry | Original operation and exact prior journal through its known recovery pair. |
| pause / resume | Opt-in protected control gate, authentic interruption requests and owner reconciliation. |
| tick | Authenticated selected cadence/budget dispatch through the same owner pipeline; standalone mode cannot dispatch. |
| log-register / log-list / log-summary / log-query | Existing bounded log protocol in SKILL.md; full logs remain intact. |

Manual and automatic origin must equal the protected accepted operation. Request
files cannot mint a grant, change their tool/owner, rewrite caller context or
promote an installed module to an active execution. Task activation is its own
existing-owner workflow. Local integration does not grant commit, push or merge.
Dependency declarations, retrieved package sources, runtime installation and
service startup each require their own selected permission.
