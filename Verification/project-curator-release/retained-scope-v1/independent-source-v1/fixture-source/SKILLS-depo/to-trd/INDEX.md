# To-TRD skill file index

This index describes reusable skill files. It is **not** the project TRD registry.
The runtime registry is `<project-root>/TRDs/INDEX.md`, generated by the helper.
Package version 2.2.0 adds explicit discovery readiness and question-and-wait
guidance while retaining schema 2 and the existing document lifecycle.

| File | Purpose | Read when |
| --- | --- | --- |
| [SKILL.md](SKILL.md) | Entry point, explicit activation, workflow, exit boundary | On explicit invocation |
| [README.md](README.md) | Installation, user commands, examples, recovery | Setup or troubleshooting |
| [ACTIONS.md](ACTIONS.md) | Stable document/migration action IDs and command mapping | Routing a maintenance operation |
| [AGENTS.md](AGENTS.md) | Skill-local authoring guidance | Editing this skill |
| [agents/openai.yaml](agents/openai.yaml) | Codex display metadata and explicit-only policy | Host discovery/configuration |
| [references/wayfinding.md](references/wayfinding.md) | Lightweight intent-capture conversation | Clarifying or resuming intent |
| [references/interaction-examples.md](references/interaction-examples.md) | Synthetic fast path, real pause, follow-up and incomplete draft | Learning the discovery boundaries |
| [references/trd-contract.md](references/trd-contract.md) | Schema 2, document states, legacy compatibility/migration, writes, and CLI | Writing or maintaining TRDs |
| [assets/trd-body-template.md](assets/trd-body-template.md) | Declarative requirement body with intentional substitution slots | Creating a document |
| [assets/example-input.json](assets/example-input.json) | Concrete valid input with no unfilled slots | Learning/testing the format |
| [scripts/trd.py](scripts/trd.py) | Standard-library file/index helper | Deterministic reads or writes |
| [tests/test_trd.py](tests/test_trd.py) | Isolated document lifecycle, migration, helper, and package checks | Maintenance verification |
| [tests/interaction-scenarios.md](tests/interaction-scenarios.md) | C01–C14 synthetic conversational cases and evidence contract | Actual-host behavioral verification |
| [ATTRIBUTION.md](ATTRIBUTION.md) | Wayfinder credit, inspected sources, adaptation notes | Provenance review |
| [licenses/wayfinder-MIT.txt](licenses/wayfinder-MIT.txt) | Retained upstream license notice | Redistribution/provenance review |

No file here contains a project-specific active-task pointer or response ledger.
Copy the entire folder so references, templates, tests, and credit stay together.
