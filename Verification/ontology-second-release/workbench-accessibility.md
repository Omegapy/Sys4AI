# Actual workbench accessibility and browser verification

The real installed service was exercised through Codex's in-app browser. Alias
search used Enter. Named controls completed draft editing, validation, exact diff
review, rejection/reopen and publication without graph dragging or color-only
cues. Errors retained entered text; the stale second tab kept its pending value.
The saved rejected revision survived reload, and the published record reopened.

The concept inspector and relation list expose the same identities as the bounded
graph. The actual inference view expanded both source-bound premises for the
Artifact conclusion; a selected inferred-graph ASK returned true. Read-only
sessions had no editing or publication controls. A literal img/onerror probe
remained text and created no image element or title change.

Visual screenshots were inspected for the review columns and narrow concept
view. The narrow content area measured 500 CSS pixels with a 500-pixel scroll
width; no horizontal page overflow was observed. This browser enforced that
minimum, so a 390-pixel run is not claimed. Temporary viewport overrides were
reset. CUA's content export is unavailable; screenshots exist in the observed
tool trace, while bounded interaction observations and exact canonical receipts
are retained in browser-evidence/ and browser-acceptance.json.
