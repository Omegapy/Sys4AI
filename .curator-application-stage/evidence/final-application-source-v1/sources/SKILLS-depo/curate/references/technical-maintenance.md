# Technical repair workflow

Select a defect or compatibility finding with exact evidence, paths, tools,
completion criteria, accepted finding hash and current target hash. Only selected
classes and budgets may enter isolated candidate work. If the cause is not
established, investigate the bounded hypothesis; do not refactor speculatively.

Candidate changes preserve existing interfaces and unrelated work. The complete
reviewed candidate enters the Broker's actual range classification, owner conflict,
source/version, independent permission and journal-budget gates before effect.
Integration runs the selected actual owner checks and preserves later human edits.
A proposal, unit check or candidate pass alone is not an integrated repair.
