# Consumer memory write policy

Canonical project files remain project-owned. This bootstrap grants the named
owner only source reading, exact-index synchronization and initialization.
Memory cannot edit canonical sources, approve proposals, delete data, export
content, or share another project's records through these grants.

Later source admission requires the existing reviewed source-registration
operation and an explicit canonical permission grant. Unregistered paths stay
excluded. No profile or retrieved text can confer that authority.
