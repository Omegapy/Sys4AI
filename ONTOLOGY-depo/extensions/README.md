# Selected project extensions

This reusable directory contains no project assertions. Destination projects
author approved extension JSON under their own `ONTOLOGY/extensions/`, with
exact locks in `ontology-advanced.yaml`. New projects receive an empty extension
selection. Existing projects require explicit adoption and destination-local
publication binding before semantic publication.

See [the advanced profile](../advanced-profile.md) and
[the extension schema](../schema/advanced-extension-v1.json). Imports and AI
suggestions first enter durable proposals and use the ordinary review/publisher
gate. Source attribution, type consistency, or a successful inference do not
authorize publication.
