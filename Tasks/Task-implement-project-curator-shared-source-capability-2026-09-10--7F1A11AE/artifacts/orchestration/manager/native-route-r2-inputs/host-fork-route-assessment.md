## Exact-tag source findings

The accompanying receipt files bind downloaded upstream rust-v0.153.4 sources by URL and SHA256. Matching version labels are not binary-equivalence proof.

1. `core/src/tools/handlers/multi_agents_v2/spawn.rs` applies a configured default role to non-full-history children and persists its name. The custom role path is therefore more specific than guessing that task_name selects a role.
2. `core/src/agent/role.rs` applies a bounded typed override set. Its feature reductions cover a small enumerated set and exclude native multi-agent controls. A discoverable default role alone does not establish disabled peer tools.
3. `app-server/src/request_processors/thread_processor.rs` accepts `thread/fork` configuration, named permissions and a beforeTurnId history boundary before creation. It reads stored parent state and rebuilds configuration. An ephemeral source may be insufficient. Omitting model/effort fields is not, by itself, evidence of effective inheritance.
4. `core/src/thread_manager.rs` creates a real native Session for a fork and records forked_from_thread_id. This is separate from parent_thread_id and from the native AgentControl spawn tree. The wrapper must retain that distinction.
5. `core/src/session/mod.rs` restores dynamic tools from recorded history when no new tools are supplied. Live fork callback and caller correlation still need testing.
