# Native protocol v1

The selected candidate transport is Codex App Server v2 over trusted broker-owned
stdio. Actual native thread, turn and item identities retain their native form.
Requested model/profile values do not prove effective settings or confinement.

Every operating mode remains blocked until current native and OS enforcement
evidence covers its entire topology, input separation and enabled tools. Missing
capabilities preserve pending work and uncertain reservations. Fixture results
cannot pass these gates. A complete proof uses the depot release protocol and
the exact host-reviewed disposable scope, with synthetic canaries only.

## Staged runtime observations

`CodexAdapter` validates the pinned generated schemas and owns request/reply
correlation on one stdio connection. Native calls construct one-use live contexts
inside that process. Typed methods never expose process/spawn or a raw protocol
forwarder. A child's effective model/effort and inherited bootstrap profile are
inspected without overrides before its separate profile selection. A mismatch
holds the child; setting the requested values afterward cannot prove inheritance.

`RuntimeCoordinator` retains complete generic, complex and extra-complex logical
teams across capacity queues. Uncertain launches retain their original slots.
Stopping inspects every actor and continues through individual failures; idle
actors and failed observations remain explicit unreconciled states.

The depot's `run-native-proof.py prepare` creates only disposable inputs, pinned
schemas and an exact review packet. Its execute route requires that packet digest.
The first stage settles bootstrap tool inheritance and sibling control before
full topology. Its child-only protected configuration is a candidate use of
[custom agent config layers](https://learn.chatgpt.com/docs/config-file/config-reference)
and `features.multi_agent`; configuration alone is not a native isolation pass.
The packet labels supported supervision limits separately from unavailable hard
model-call, token or lifetime-spawn caps. Full NP-001 through NP-014 evidence and
final-source repetition remain required for release.
